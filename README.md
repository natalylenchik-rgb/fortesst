# Документ. — прототип сервиса документов

Интерактивный фронтенд-прототип бесплатного сервиса для малого бизнеса: шаблоны документов, реквизиты компании и быстрый мастер создания.

## Запуск

```bash
npm install
npm start
```

Сервер слушает `0.0.0.0:5173`, поэтому порт `5173` можно открыть через встроенный
предпросмотр рабочей среды. Для проверки production-сборки используйте:

```bash
npm run build
npm run preview
```

Команда предпросмотра использует тот же адрес `0.0.0.0:5173`. Конфигурация также
разрешает проксирующие домены интерфейса предпросмотра Vite.

> `0.0.0.0` — это адрес привязки сервера внутри контейнера, а не публичная ссылка.
> Чтобы открыть сайт из браузера вне контейнера, среда должна предоставить
> собственный port-forwarding URL для порта `5173`. Если такого URL в интерфейсе
> нет, открыть контейнерный `localhost` с другого компьютера невозможно.

### Как посмотреть сайт без встроенного предпросмотра

1. Скачайте репозиторий и запустите `npm install && npm start` на своём компьютере,
   затем откройте `http://localhost:5173`.
2. Либо выполните `npm run build` и загрузите содержимое каталога `dist/` на любой
   статический хостинг (GitHub Pages, Netlify Drop, Cloudflare Pages). Сборка
   использует относительные пути и работает в том числе из подпапки сайта.

### Автономная версия без сервера

```bash
npm run build:standalone
```

Команда создаёт `standalone/index.html`: CSS и JavaScript встроены прямо в
HTML, внешние шрифты отключены. Файл можно открыть двойным щелчком через
`file://` без Node.js, локального сервера и доступа к интернету. Автономный HTML
хранится в Git как обычный текстовый файл, без бинарного ZIP-архива.

## Возможности прототипа

- каталог шаблонов по категориям;
- поиск по документам;
- мастер создания трудового договора;
- сохранение реквизитов компании в `localStorage`;
- адаптивная навигация и интерфейс для мобильных устройств.
